# По делу — To-do list

Приложение со списком задач на русском языке, без зависимостей и сборки.

## Возможности

- Добавление, редактирование и удаление задач.
- Отметка выполнения, фильтры и прогресс.
- Сохранение в `localStorage` и обновление при изменениях в другой вкладке.
- Адаптивный интерфейс, управление с клавиатуры.

Задачи хранятся только в текущем браузере. Синхронизации между устройствами нет.

## Запуск

```sh
python3 -m http.server 3000
```

Откройте http://localhost:3000. Сервер запускается из папки проекта.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку с приложением и папку **/ (root)**. Сохраните настройки.

## Структура

- `index.html` — интерфейс.
- `styles.css` — стили.
- `app.js` — логика и сохранение.

Проверка синтаксиса: `node --check app.js`.
